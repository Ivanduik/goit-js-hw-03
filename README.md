# goit-js-hw-03

Домашнє завдання №3 з JavaScript: масиви.

## Завдання

1. **Генератор slug** (`js/task-1.js`): `slugify(title)` повертає рядок у нижньому регістрі зі словами, розділеними дефісами.
2. **Композиція масивів** (`js/task-2.js`): `makeArray(firstArray, secondArray, maxLength)` створює новий масив і за потреби обмежує його довжину.
3. **Фільтрація чисел** (`js/task-3.js`): `filterArray(numbers, value)` повертає новий масив чисел, які строго більші за `value`.

## Перевірка

Відкрий `index.html` у браузері та переглянь результати у **DevTools → Console**. У всіх трьох JavaScript-файлах залишено виклики `console.log` з умов завдань.

## Публікація

Після завантаження проєкту до публічного репозиторію GitHub увімкни **Settings → Pages → Deploy from a branch → main → /(root)**. Перевір живу сторінку та додай її URL у поле **About → Website** репозиторію.
